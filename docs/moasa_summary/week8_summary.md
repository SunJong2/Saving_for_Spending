## 1. 새로 배운 것 / 개념

### 인라인 SVG + currentColor
- 아이콘을 이미지가 아니라 SVG 코드로 직접 삽입 → 외부 의존성 0
- `stroke="currentColor"` → 아이콘 색이 부모의 `color`를 상속. 탭 활성 시 CSS(`.tab.active { color }`)만으로 아이콘 색이 자동 변경됨
- `viewBox`(내부 좌표계)와 `width/height`(실제 크기)는 분리 — SVG는 글자가 아니라 도형이라 `font-size`가 안 먹음

### CSS 디자인 토큰
- `:root` 변수로 색을 중앙 관리 → 한 곳 수정으로 전체 반영. `#7C4DFF` 하드코딩 → `var(--primary)`
- `background-clip: text` + `color: transparent`로 글자에 그라데이션 입히는 기법(검토 후 단색 채택)

### SQL 집계 — GROUP BY
- 지금까지의 "행을 그대로 조회"와 달리, **같은 값끼리 묶어 한 줄로 요약**
- `SELECT category, SUM(amount) AS total ... GROUP BY category ORDER BY total DESC`
- 통계 막대는 최댓값 기준 상대 비율(`total / max * 100`)로 그림 — 진행률 바 트릭 재사용
- **빈 집계는 에러가 아님**: 0행이면 200 + 빈 배열이 정상 (자원 부재 404와 컬렉션 비어있음은 다름)

### PWA
- 설치 조건: `manifest.json`(name · icons 192/512 · start_url · display) + fetch 핸들러가 있는 서비스워커 + HTTPS
- 서비스워커 **network-first 전략** 선택: 온라인이면 항상 최신, 오프라인이면 캐시 폴백. 개발 중 캐시로 "수정이 반영 안 되는" 함정을 피하려는 의도. API 응답(동적·인증)은 캐시 제외
- SW는 보안 컨텍스트(HTTPS/localhost)에서만 등록됨 → 폰 LAN IP(http) 테스트로는 확인 불가, 배포본에서 확인

### stateless JWT의 성질 (재확인)
- 데모 재시드로 계정을 삭제해도, 그 유저의 토큰은 서명·만료가 유효하면 여전히 통과 → `/goals/current`가 404(만료 401이 아님)
- 토큰은 DB에 유저가 남아있는지 모름(무상태). 외래키(FK)가 정합성의 backstop
- `textContent` vs `innerHTML`: 숫자 등 신뢰 데이터엔 innerHTML 가능, 유저 입력엔 textContent

## 2. 설계 판단 기록 (자소서 · 면접 재료)

- **아이콘: 라이브러리(Lucide) 대신 인라인 SVG** — "프레임워크 없음" 철학 + 아이콘이 소수라 라이브러리 의존성 0이 유리
- **자리마다 어울리는 요소** — 기능 아이콘(탭바·휴지통)만 SVG로, 빈 상태의 큰 타겟(🎯)은 이모지 유지. "앱 전체가 통일"이 아니라 "같은 맥락 안에서 통일"
- **저금통 그래픽: 3D 이미지/일러스트 대신 미니멀 타이포 히어로** — 래스터 3D는 브랜드 그라데이션과 안 맞고 확대 시 흐림·재색칠 불가·데이터 연동 불가. 시간 대비 효과와 브랜드 일관성 우선
- **그라데이션 절제** — 강조색을 전부에 쓰면 강조가 아니게 됨 → 그라데이션은 주 행동(CTA 버튼)에만, 히어로 숫자는 단색
- **남은 금액 표시** — 퍼센트만으론 진행률 바와 중복 → "목표까지 N원 · N%". 단, 표시 금액은 **절대 반올림 금지**(현재 + 남은 = 목표가 어긋나면 신뢰 훼손)
- **통계 위치(A안)** — 새 탭 추가·홈 확장 대신 히스토리 섹션에 배치. 탭을 안 늘리고 "지금까지 해낸 것" 테마와 부합
- **히스토리 빈 상태 분기** — "완료 목표 없음"과 "목표 자체 없음"은 다른 상황. `/goals/current`로 확인해, 진행 중 목표가 있으면 막다른 "첫 목표 만들기" 대신 홈으로 유도
- **시드 스크립트는 repo에 포함** — 재현 가능한 데모 세팅의 증거물. 비밀 값 없음(데모 계정은 공개용, 실제 비밀은 .env)
- **파비콘 'ㅁ'을 글자가 아닌 도형으로** — 렌더링 환경의 한글 폰트 의존성 회피
- **데모 시나리오 설계** — 완료 목표 2개(마감 전/후 달성)로 "N일 빠르게"·"끝까지 해냈어요" 두 문구를, 한 목표를 초과 적립시켜 "107% 달성"을 시연. 카테고리별 금액 분포로 통계 막대 서열까지 의도적으로 구성

## 3. 겪은 이슈 (실전 기록)

1. **SVG 복붙 잔재** — 트로피 아이콘 끝에 홈 아이콘의 polyline(문짝)이 딸려옴. 아이콘은 `<path>` 세트를 통째로 가져와야 하며 발췌하면 깨짐
2. **`.map()`을 숫자에 사용** — `current_amount`(숫자)에 배열 전용 `.map`을 씀 → 스크립트 전체가 멈춰 화면이 빈 채로 뜸. 목록 렌더 패턴을 단일 값에 잘못 적용
3. **통계 응답 key 오타** — `return {"stats:": ...}` — key에 콜론이 붙어 프론트의 `data.stats`가 `undefined`
4. **업로드 버전 불일치** — edit-goal이 스피너·head 태그가 빠진 옛 버전으로 되돌아가 있던 것을 발견 → 재적용
5. **히스토리 막다른 버튼** — 진행 중 목표가 있는데도 "첫 목표 만들기"가 떠서, 누르면 409로 홈에 튕김 → 상태 분기로 해결
6. **theme-color 메타는 CSS 변수 불가** — 리터럴 hex만 받음 → 토큰화 대상에서 제외
